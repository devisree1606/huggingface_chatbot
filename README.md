# AI Text Generator using Hugging Face and Streamlit

## Project Overview

This project is a simple AI Text Generator built using Python, Streamlit, and Hugging Face Inference API.

The application allows users to enter a question or text and receive an AI-generated response using the selected Hugging Face language model.

## Technologies Used

- Python
- Streamlit
- Hugging Face Hub
- Hugging Face Inference API
- GPT-OSS-120B Model

## Features

- Simple and user-friendly Streamlit interface
- Accepts user questions as input
- Sends the input to a Hugging Face AI model
- Generates an AI-based response
- Displays the response directly in the web application
